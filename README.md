# AssemblyProjects

MARIE assembly coursework and simulator-related artifacts.

## Trust warning

Several files here are **binaries / simulator jars** (for example `MarieSim.jar`) without a full auditable source tree for every artifact.

- Do **not** run jar files from this repo on production or sensitive hosts.
- Prefer reading `.mas` / listing files; treat jars as third-party tooling you have not built yourself.
- For a security-oriented portfolio, prefer source-first repos or clearly labeled vendor tooling with checksums.

Authorized learning / coursework use only.
